# Colour a string cyan with ANSI escapes

Internal function for
[`print_sujimichi()`](https://matutosi.github.io/sujimichi/reference/sujimichi_lines.md).
An empty string is left empty, so an unmarked line is not coloured.

## Usage

``` r
ansi_cyan(x)
```

## Arguments

- x:

  A string.

## Value

A string.
