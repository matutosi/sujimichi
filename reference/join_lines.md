# Join the lines of a paragraph into one string

Internal function for
[`split_sentences()`](https://matutosi.github.io/sujimichi/reference/as_sentences.md).

## Usage

``` r
join_lines(text)

move_mark_after_close(text, mark)
```

## Arguments

- text:

  A string.

- mark:

  A string used as the split mark.

## Value

A string.
